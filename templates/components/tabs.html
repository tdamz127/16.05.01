TÀI LIỆU HƯỚNG DẪN KẾT NỐI API
1. Lấy danh sách Đơn hàng & Nhóm gán (Export API)

API này được sử dụng để hệ thống thứ 3 kéo thông tin các đơn hàng đang Active về xử lý.

GET http://localhost:5005/api/export_orders
Cấu trúc phản hồi (JSON Response):
{
"status": "success",
"total": 2,
"data": [
{
  "order_id": "1900004704665923584",
  "owner_account": "accmua1@gmail.com",
  "owner_group": "nhom_goc_a",
  "assigned_group": "nhom_telegram_1",
  "status": 10,
  "is_confirmed": true
}
]
}
Trường (Key) Kiểu dữ liệu Ý nghĩa
order_idStringMã đơn của Bybit.
owner_accountStringMã tài khoản đang giữ đơn này.
owner_groupStringMã nhóm của tài khoản đang giữ đơn này.
assigned_groupStringNhóm tài khoản được gán đơn này. Nếu chưa gán sẽ là chuỗi rỗng "".
statusIntegerTrạng thái đơn (10: Chờ Pay, 20: Chờ Nhả, 50: Hoàn Thành, v.v...).
is_confirmedBooleanTrue nếu đơn đã được xác nhận qua Webhook. Mặc định là False.
2. Báo cáo / Gỡ Xác nhận Đơn (Callback API)

API này dùng để hệ thống bên thứ 3 bắn tín hiệu báo cáo về lại cho Hệ thống Dispatcher khi người dùng bấm "Xác nhận đơn" (hoặc Gỡ xác nhận).

POST http://localhost:5005/api/confirm_order
Body Payload (JSON):
{
  "order_id": "1900004704665923584",
  "action": "confirmed", 
  "note": "Đã chuyển khoản xong"
}
Trường (Key) Kiểu dữ liệu Ý nghĩa
order_idStringMã đơn hàng cần xác nhận (Bắt buộc).
actionStringTruyền confirmed để Xác nhận. Truyền unconfirmed để Gỡ xác nhận.
noteStringGhi chú thêm (Không bắt buộc).
Phản hồi Thành công (JSON):
{
  "status": "success",
  "message": "Đã ghi nhận trạng thái xác nhận cho đơn 1900004704665923584"
}
